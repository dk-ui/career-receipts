# inbox/

**Drop zone for the whole vault.** Put any file here and say "file my inbox". Claude works out
what it is, files it in the right place under a sensible name, updates that folder's notes,
and deletes the original. You never need to know which folder something goes in.

Good things to drop: resumes (old ones too), cover letters, your LinkedIn PDF, headshots,
screenshots of your work, decks, case studies, award or recognition emails, performance
reviews, reference letters, certificates.

**Don't drop:** passports, driver's licenses, Social Security cards, bank or pay statements,
or anything with an ID or account number on it. Claude will refuse to file those anyway, but
it's better if they never land here.

**Nothing in this folder is saved to history.** It's excluded from git on purpose, because a
raw drop hasn't been checked for ID numbers yet. Files get saved once they're filed. That
means **this folder should be empty between sessions**. Don't use it as storage.
