# resumes/

Every past resume version, named `YYYY-MM-<label>`, oldest to newest. **This is history,
not the working copy.** The live CV is `cv.md` at the vault root (or `career-ops/cv.md` if
career-ops is installed), rebuilt from the vault by the `sync-cv` skill.

Old versions are worth keeping. They show phrasing that worked, and dates and numbers you've
since forgotten. Any number on an old version still needs a row in the evidence ledger before
it goes on the live CV.
