# examples/

**Everything in here is fiction.** It shows what a career vault looks like after a few weeks
of use, so you can see the finished state before you start your own.

- [sample-vault/](sample-vault/README.md) belongs to **Robin Castellane**, an invented
  operations lead. The person, the organizations and every number are made up. The images
  are placeholders labeled "sample screenshot", not real product screens.

The vault's tools skip this folder, so it never appears in your `MANIFEST.md`. Setup offers to
delete it once you've had a look.
