## Status key

| | Meaning |
|---|---|
| 🟢 **SOURCED** | A file in this vault shows the number |
| 🟡 **DERIVED** | Calculated or estimated from something documented. Fine to use if you can explain the math |
| 🔴 **GAP** | No file yet, but one could exist. Go find it. **Never used on a CV** |
| 🔵 **SELF-ATTESTED** | From memory, and the document is gone (it stayed with the employer), or carried over from an old resume. Fine to use: be ready to say "that's from memory" |
