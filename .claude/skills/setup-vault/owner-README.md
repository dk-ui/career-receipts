# Career vault

A private, complete record of my working life: every job, project and degree, the files that
prove what I did, and the photos that go with them. **This is the source of truth.** My CV,
review notes and any job search read from it, never the other way around.

> New here? Read [START-HERE.md](START-HERE.md). Navigating? [index.md](index.md) lists every file.

```
career-vault/        ← everything about my work. Private, local.
   ├──→ cv.md        my live CV, rebuilt from the vault. Every number traces to a file.
   └──→ career-ops/  optional job-search engine, if I install it.
```

## Status flags

Each chapter carries one: ⚪ not started · 🔴 claims, no files yet · 🟡 partial · 🟢 strong.
It's a progress bar, not a grade. A claim with no file behind it is a gap, not a fact, and the
gap lists show which files are most worth finding.

## Rules

Agent rules live in [CLAUDE.md](CLAUDE.md). The short version: nothing leaves this folder
without my OK, ID numbers never get filed, and every number on my CV has a source here.
